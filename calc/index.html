Live: updates by itself

opens your game in a new tab linked to this page and copies the reader. In that tab press F12, pick Console, paste, press Enter.. This device has no Console, so in that tab you run the FF live bookmark instead (below). From then on this page follows the game live: a new day shows here within a second or two. Keep the game tab open (side by side with this page works best).

No Console? Drag FF live to your bookmarks bar, then click it on your game tab. On a tablet or phone? Show the tablet steps.

  • Make the bookmark once: Bookmark any page, edit that bookmark, name it FF live and paste over its address.
  • Run it on the game tab: in Safari open Bookmarks and tap it; in Chrome type FF live in the address bar and tap the bookmark.
  • On a computer? Show the Console steps.

Or once, by hand

  1. Open your game in Chrome, press F12, pick Console. The first time, type allow pasting and press Enter.
  2. paste it into the Console, press Enter. A box appears at the bottom right of the game (the first time takes under half a minute; it remembers the setup after that). Then it follows the game live, a second or two behind it. It only reads.
  3. On your game tab, run the FF live bookmark (make it above). A box appears at the bottom right of the game (the first time takes under half a minute). Then it follows the game live. It only reads.
  4. ClickTap Copy data there, then paste in the box here (or anywhere on this page) (touch and hold, then Paste). It fills straight away. Locked values () are kept.
